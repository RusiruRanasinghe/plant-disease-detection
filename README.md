# Plant Disease Detection using Deep Learning

deep learning solution for detecting and classifying plant diseases from leaf images using Transfer Learning.



* **Dataset**: PlantVillage Dataset (54,000+ images, 38 disease classes)
* **Models**: CNN from Scratch, ResNet50, EfficientNetB0, MobileNetV2
* **Framework**: TensorFlow/Keras
* **Platform**: Trained on Kaggle (GPU T4 x2)



## Technologies



* Python 3.8+, TensorFlow 2.x, Keras
* NumPy, Pandas, Matplotlib, Seaborn
* OpenCV, Scikit-learn, Gradio
